1. **即看即懂**：无需教程，点开就知道怎么玩
2. **差一点就过**：难度曲线设计，让玩家总觉得"再来一把就能过"
3. **社交传播**：省份排名 + 分享复活，自带传播基因

## 2. 核心玩法走读

### 一局完整流程

1. **进入游戏**：看到一叠堆叠的卡片，卡片上有不同图案（动物 emoji）
2. **观察局面**：上层卡片亮色可点，下层卡片灰色被压住不能点
3. **选择卡片**：点击一张卡片，卡片飞入下方卡槽（共7个位置）
4. **三消判定**：卡槽中出现3个相同图案时，自动消除并播放动画
5. **继续选择**：被压住的卡片解锁，继续选择
6. **失败条件**：卡槽7个位置满了，但凑不出3个相同图案 → 游戏结束
7. **胜利条件**：所有卡片消除完毕，卡槽也清空 → 通关

### 玩家决策点
- **选哪张卡**：观察哪些图案在卡槽里快凑齐了，优先点对应图案
- **风险控制**：卡槽快满时，谨慎选择，避免引入新图案
- **道具使用时机**：撤回/洗牌/提示，什么时候用最划算

## 3. 玩法架构

### 瞬时循环（单局内）
```
观察堆叠 → 点击卡片 → 卡槽新增 → 三消判定 → 解锁新卡片 → 再观察
```

### 单局循环
```
开始关卡 → 游玩 → 胜利/失败 → 结算 → 下一关/重开
```

### 长期循环
```
闯关 → 解锁新关卡 → 排行榜 → 分享复活 → 挑战更高难度
```

## 4. 核心机制

### 4.1 卡片堆叠规则
- 卡片分为多层，上层卡片会压住下层卡片
- 只有完全露出（没有被上层卡片压住）的卡片可以点击
- 被压住的卡片显示为半透明灰色
- 点击后卡片从堆中移除，下面的卡片可能解锁

### 4.2 卡槽规则
- 卡槽共 7 个位置
- 点击卡片后，卡片按顺序放入卡槽
- 当卡槽中某图案达到 3 个时，自动消除该图案的 3 张卡片
- 卡槽满 7 个且无法消除时，游戏失败

### 4.3 关卡难度曲线

| 关卡 | 图案种类 | 卡片总数 | 堆叠层数 | 难度说明 |
|---|---|---|---|---|
| 第1关 | 3种 | 18张 | 2层 | 新手教学，几乎必过 |
| 第2关 | 4种 | 27张 | 3层 | 开始有挑战 |
| 第3关 | 5种 | 36张 | 3层 | 中等难度 |
| 第4关 | 6种 | 45张 | 4层 | 较难 |
| 第5关+ | 7种+ | 54张+ | 4层+ | 地狱难度 |

**设计要点**：第一关必须简单，让玩家快速获得正反馈；后面关卡逐渐加难度，制造"差一点就过"的感觉。

## 5. 道具系统

| 道具 | 效果 | 初始数量 | 获取方式 |
|---|---|---|---|
| 撤回 | 撤销上一步操作，卡片退回堆叠 | 3次 | 分享获得 + 看广告 |
| 洗牌 | 重新排列所有未消除卡片的图案 | 3次 | 分享获得 + 看广告 |
| 提示 | 高亮一张最优卡片 | 3次 | 看广告获得 |

## 6. 社交传播机制（P1）

### 6.1 省份排行榜
- 通关后显示"你所在省份的通关排名"
- 类似羊了个羊的省份大战，激发地域荣誉感

### 6.2 分享复活
- 游戏失败后，"分享给好友即可复活一次"
- 复活时清空卡槽中一半卡片

### 6.3 好友比拼
- 显示好友的最高关卡
- "你已经超过了 XX% 的好友"

## 8. 生产检查

| 责任面 | 风险评估 |
|---|---|
| 运行性能 | 卡片数量少（<100张），Canvas渲染无压力 |
| 状态数据 | 本地存档：最高关卡、道具数量 |
| 内容生产 | 图案用 emoji 即可，后续再换美术 |
| UI与输入 | 竖屏设计，单指操作，适配手机屏幕 |
| 集成与QA | 先在浏览器Demo验证，再迁移到抖音小游戏框架 |

## 9. 技术方案

- **第一阶段**：HTML+CSS+JS 开发 Demo（当前已完成）

- 语言：JavaScript
- 渲染：Canvas 2D（抖音小游戏原生）
- 开发工具：抖音开发者工具
- 代码托管：GitHub
