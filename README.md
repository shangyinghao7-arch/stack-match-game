# 堆叠消消乐 🎮

抖音小游戏 - 堆叠三消类休闲游戏

## 游戏介绍

类似"羊了个羊"/"抓大鹅"的堆叠消除游戏：
- 屏幕上有一堆堆叠的卡片
- 点击卡片移入下方卡槽（共7个位置）
- 凑齐3个相同图案自动消除
- 卡槽满了游戏失败，清空所有卡片通关

## 快速开始

### 1. 试玩 Demo
直接用浏览器打开 `demo/index.html` 即可游玩。

### 2. 抖音小游戏开发
1. 下载 [抖音开发者工具](https://developer.open-douyin.com/)
2. 打开开发者工具，选择"导入项目"
3. 选择 `douyin-minigame/` 目录
4. 填入你的 AppID（或先用测试号）

## 玩法规则

1. 只有**上层未被压住**的卡片可以点击（亮色卡片）
2. 被压住的卡片显示为灰色，不能点击
3. 点击卡片后，卡片进入下方卡槽
4. 卡槽中有 **3个相同图案** 时，自动消除
5. 卡槽 **7个位置满了** 且无法消除 → 失败
6. **消除所有卡片** 且卡槽清空 → 胜利

## 道具系统

- **撤回** ↩️：撤销上一步操作
- **洗牌** 🔀：重新排列所有卡片的图案
- **提示** 💡：高亮一张最优卡片
